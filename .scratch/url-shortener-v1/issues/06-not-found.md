# 06: 없는 Code 처리

**What to build:** 존재하지 않는 Code로 들어온 사람은 빈 화면이나 서버 오류 대신 "링크를 찾을 수 없음" 페이지를 본다. 응답 상태는 `404`다. 앞자리 0이 붙은 Code와 bigint 범위를 넘는 숫자도 같은 방식으로 처리해서, 하나의 Short Link가 여러 주소로 접근되지 않게 한다.

**Blocked by:** 05 (단일 이미지 — 백엔드가 프론트 서빙)

**Status:** ready-for-agent

- [x] 프론트에 "링크를 찾을 수 없음" 페이지가 있고, 메인 페이지로 돌아가는 링크를 둔다.
- [x] 숫자 형태이지만 존재하지 않는 Code는 HTTP `404`와 함께 not-found 페이지를 응답한다.
- [x] `/007`처럼 앞자리가 0인 경로는 해당 Code가 있어도 `404`로 응답한다.
- [x] bigint 범위를 넘는 숫자 경로는 서버 오류 없이 `404`로 응답한다.
- [x] HTTP 경계 테스트가 위 세 경우의 `404`를 검증한다.
- [x] 프론트 페이지 테스트가 not-found 페이지의 문구와 메인 페이지 링크를 검증한다.
