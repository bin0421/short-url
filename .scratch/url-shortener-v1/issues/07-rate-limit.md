# 07: 링크 생성 요청 제한

**What to build:** 한 IP가 1분 안에 Short Link를 너무 많이 만들면 생성 요청이 거부되고, 방문자는 "잠시 후 다시 시도" 안내를 본다. 다른 IP와 리다이렉트는 영향을 받지 않는다(ADR 0002). 리버스 프록시 뒤에서도 실제 방문자 IP 기준으로 동작한다.

**Blocked by:** 02 (Target URL 규칙과 오류 메시지)

**Status:** ready-for-agent

- [x] Bucket4j 인메모리 버킷으로 생성 API에 IP당 분당 10회 제한을 건다.
- [x] 11번째 요청은 `429`와 `ProblemDetail` 본문으로 거부된다.
- [x] 리다이렉트 요청은 제한되지 않는다.
- [x] Spring의 forwarded header 처리를 켜서 `X-Forwarded-For`의 클라이언트 IP를 기준으로 제한한다.
- [x] HTTP 경계 테스트가 같은 IP의 11번째 요청 `429`, 다른 IP의 정상 처리, 리다이렉트 무제한을 검증한다.
- [x] 메인 페이지는 `429` 응답에 "잠시 후 다시 시도" 안내를 표시하고, 프론트 페이지 테스트가 이를 검증한다.
