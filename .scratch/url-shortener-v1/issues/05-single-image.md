# 05: 단일 이미지 — 백엔드가 프론트 서빙

**What to build:** Docker 이미지 하나만 실행하면 메인 페이지, 생성 API, 리다이렉트가 모두 동작한다. multi-stage 빌드에서 프론트를 먼저 빌드하고, 그 결과를 Spring Boot의 정적 리소스에 넣어 jar를 만든다.

**Blocked by:** 01 (워킹 스켈레톤)

**Status:** ready-for-agent

- [x] 저장소 루트의 multi-stage Docker 빌드가 프론트 빌드 → 백엔드 jar 빌드 → 실행 이미지 순서로 이미지 하나를 만든다.
- [x] 이미지를 Postgres와 함께 실행하면 `/`에서 메인 페이지가 열린다.
- [x] 같은 컨테이너에서 `/api/**`는 API로, 숫자 경로는 리다이렉트로 동작한다.
- [x] 프론트 정적 자산 경로가 숫자 리다이렉트 라우트와 충돌하지 않는다.
- [x] 공개 base URL, 서비스 host, DB 접속 정보를 환경변수로 넣을 수 있다.
- [x] HTTP 경계 테스트가 `/` 요청에 HTML이 반환됨을 검증한다(빌드된 프론트가 포함된 경우).
