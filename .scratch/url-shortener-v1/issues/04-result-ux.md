# 04: 결과 화면 편의 기능

**What to build:** 방문자가 결과 Short Link를 버튼 하나로 복사하고, 복사됐는지 확인할 수 있다. 제출 중에는 중복 제출이 막히고, Enter 키로도 제출할 수 있다. 결과를 받은 뒤 페이지를 새로 고치지 않고 바로 다음 URL을 줄일 수 있다.

**Blocked by:** 01 (워킹 스켈레톤)

**Status:** ready-for-agent

- [x] 결과 옆 복사 버튼을 누르면 `shortUrl`이 클립보드에 들어가고, 복사됐다는 표시가 보인다.
- [x] 요청이 진행되는 동안 제출 버튼이 비활성화된다.
- [x] 입력창에서 Enter 키를 누르면 제출된다.
- [x] 결과가 표시된 상태에서 새 Target URL을 입력해 제출하면 새 결과로 바뀐다.
- [x] 프론트 페이지 테스트가 복사(클립보드 대체), 제출 중 비활성화, Enter 제출, 연속 제출을 검증한다.
