# Code는 생성 순서대로 매긴 10진수 순번

Code는 DB가 발급하는 순번을 10진수 그대로 쓴다(`/1`, `/2`, …). 사용자가 "단순 숫자"로 줄어드는 주소를 원했기 때문이다. 그 대가로 누구나 Code를 차례로 열어 모든 Target URL을 볼 수 있고, 생성된 Short Link 수도 드러난다. 로그인 없는 공개 서비스라 이 노출을 감수하기로 했다. 같은 Target URL을 다시 제출하면 새 Code를 만들지 않고 기존 Short Link를 돌려준다.

## Considered Options

- **base62 인코딩**(`/b9`): 더 짧지만 숫자가 아니어서 요구와 맞지 않는다.
- **랜덤 숫자**: 열거는 막지만 길이가 늘어나고 충돌 처리가 필요하다.
